# 🎮 DuoFinder Bot

Telegram-бот для поиска напарников в играх. Помогает найти не просто «тело для катки», а человека, с которым комфортно и результативно играть.

## ✨ Функции

### Профиль
- 👤 **Расширенный профиль** — игра, ранг, роль, время, стиль игры, цель, голос, опыт
- 🎮 **Динамические игры** — админ добавляет игры без правки кода
- 🏆 **Ранги и роли для каждой игры** — свои наборы для Dota 2, CS2, Valorant, LoL и др.

### Поиск
- 🔍 **Поиск напарников** с фильтрами:
  - 🎯 По игре и рангу
  - 👤 По роли
  - 🕐 По времени
  - ⭐ По минимальному рейтингу
  - 🔥 По стилю игры
  - 🎯 По цели
  - 🎤 По голосу
  - 📊 По опыту
  - 🚫 Без токсиков
  - ⚡ Быстрый поиск
- 🔍 **Все фильтры** — комбинированный поиск

### Чат
- 💬 **Встроенный чат** между игроками
- 📬 **Входящие** — список диалогов с непрочитанными
- 📜 **История сообщений** — полный диалог
- 🔍 **Поиск по сообщениям** — `/search <текст>`
- 🗑 **Удаление диалога**
- 🚫 **Блокировка** пользователей
- ⏱ **Лимит** — 20 сообщений в час (защита от спама)

### Оценка и жалобы
- ⭐ **Оценка после игры** — звёзды 1–5 + теги (Ментор, Токсик, Ливер и др.)
- 📊 **Автоматический пересчёт рейтинга** по формуле
- 🚨 **Жалобы** на игроков — 5 причин
- 🚫 **Автоскрытие** токсиков при 3+ жалобах за 7 дней
- 🛡 **Антифрод** — защита от накрутки рейтинга (возраст аккаунта, профиль, взаимодействие)

### Уведомления
- 🤝 **Взаимный мэтч** — когда оба игрока написали друг другу
- ⭐ **Напоминание оценить** напарника через час после оценки
- 📝 **Напоминание заполнить профиль** через 24 часа после регистрации

### Админ-панель
- 👑 **Статистика** — пользователи, поиски, сообщения, жалобы
- 👥 **Список пользователей** с пагинацией
- ⭐ **Управление рейтингом** — вручную через команды или кнопки
- 🎮 **Управление играми** — добавление, удаление, вкл/выкл
- 🏆 **Управление рангами** — для каждой игры отдельно
- 🎯 **Управление ролями** — для каждой игры отдельно
- 🚨 **Просмотр жалоб** — все жалобы с пагинацией
- 🚫 **Скрытие/возврат** пользователей
- 🛡 **Антифрод-проверка** — `/check_antifraud <id>`
- 🔔 **Статистика уведомлений** — `/notifications`

## 📋 Команды

### Для пользователей

| Команда | Что делает |
|---|---|
| `/start` | Регистрация |
| `/help` | Все команды |
| `/cancel` | Отмена |
| `/profile` | Заполнить профиль (8 шагов) |
| `/me` | Посмотреть профиль |
| `/find` | Найти напарника с фильтрами |
| `/msg_<id>` | Написать напарнику |
| `/reply` | Ответить последнему |
| `/inbox` | Входящие сообщения |
| `/chat <id>` | Диалог с игроком |
| `/unread` | Непрочитанные |
| `/search <текст>` | Поиск по сообщениям |
| `/delete_chat <id>` | Удалить диалог |
| `/block <id>` | Заблокировать |
| `/unblock <id>` | Разблокировать |
| `/blocked` | Список заблокированных |
| `/rate <id>` | Оценить напарника (с антифродом) |
| `/my_rating` | Статистика оценок |
| `/recent_ratings` | Последние оценки |
| `/report <id>` | Пожаловаться |
| `/my_reports` | Жалобы на тебя |
| `/developer` | О разработчике |

### Для админа

| Команда | Что делает |
|---|---|
| `/admin` | Панель с кнопками |
| `/admin_help` | Помощь админа |
| `/stats` | Статистика бота |
| `/users` | Список пользователей |
| `/user <id>` | Карточка пользователя |
| `/find_user <username>` | Поиск по нику |
| `/set_rating <id> <значение>` | Установить рейтинг |
| `/get_rating <id>` | Посмотреть рейтинг |
| `/reset_rating <id>` | Сбросить на 5.0 |
| `/list_games` | Список игр |
| `/add_game <название> [эмодзи]` | Добавить игру |
| `/del_game <название>` | Удалить игру |
| `/toggle_game <название>` | Вкл/выкл игру |
| `/ranks` | Все ранги по играм |
| `/roles` | Все роли по играм |
| `/add_rank <игра> \| <ранг>` | Добавить ранг |
| `/del_rank <игра> \| <ранг>` | Удалить ранг |
| `/add_role <игра> \| <роль>` | Добавить роль |
| `/del_role <игра> \| <роль>` | Удалить роль |
| `/reports` | Список жалоб |
| `/hide_user <id>` | Скрыть игрока |
| `/unhide_user <id>` | Вернуть игрока |
| `/antifraud` | Справка антифрода |
| `/check_antifraud <id>` | Проверить пользователя |
| `/notifications` | Статистика уведомлений |

- **Python 3.10+**
- **aiogram 3** — Telegram-боты
- **SQLite** — база данных
- **aiohttp-socks** — прокси (для локального запуска)
- **python-dotenv** — переменные окружения
