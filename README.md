# 🎮 DuoFinder Bot

Telegram-бот для поиска напарников в играх. Помогает найти не просто «тело для катки», а человека, с которым комфортно и результативно играть.

## ✨ Функции

- 👤 **Профиль** — игра, ранг, роль, время
- 🔍 **Поиск напарников** с фильтрами: роль, время, минимальный рейтинг, без токсиков
- 💬 **Чат** между игроками — пересылка сообщений, история, входящие
- ⭐ **Рейтинг поведения** — оценка после игры, ручное управление админом
- 👑 **Админ-панель** — статистика, пользователи, рейтинги, игры
- 🎮 **Динамические игры** — админ добавляет игры без правки кода

## 📋 Команды

### Для пользователей

| Команда | Что делает |
|---|---|
| `/start` | Регистрация |
| `/profile` | Заполнить профиль |
| `/me` | Посмотреть профиль |
| `/find` | Найти напарника (с фильтрами) |
| `/msg_<id>` | Написать напарнику |
| `/reply` | Ответить последнему |
| `/inbox` | Входящие сообщения |
| `/chat <id>` | Диалог с игроком |
| `/unread` | Непрочитанные |
| `/cancel` | Отмена |

### Для админа

| Команда | Что делает |
|---|---|
| `/admin` | Панель с кнопками |
| `/stats` | Статистика бота |
| `/users` | Список пользователей |
| `/user <id>` | Карточка пользователя |
| `/find_user <username>` | Поиск по нику |
| `/set_rating <id> <значение>` | Установить рейтинг |
| `/get_rating <id>` | Посмотреть рейтинг |
| `/reset_rating <id>` | Сбросить на 5.0 |
| `/list_games` | Список игр |
| `/add_game <название> [эмодзи]` | Добавить игру |
| `/del_game <название>` | Удалить игру |
| `/toggle_game <название>` | Вкл/выкл игру |
| `/admin_help` | Помощь |

## 🛠 Технологии

- **Python 3.10+**
- **aiogram 3** — Telegram-боты
- **SQLite** — база данных
- **aiohttp-socks** — прокси
- **python-dotenv** — переменные окружения
